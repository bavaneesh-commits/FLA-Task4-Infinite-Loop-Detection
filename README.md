## Objective

The objective of this project is to study infinite-loop detection using
Formal Language and Automata concepts and demonstrate practical detection
using static analysis, runtime monitoring and bounded simulation.

## Techniques Used

- Runtime Timeout Analysis
- Static Analysis using Python AST
- Bounded Loop Simulation
- Turing Machine Simulation
- Static vs Runtime Comparison
- Result Visualization
